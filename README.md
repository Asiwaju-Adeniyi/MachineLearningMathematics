# Essential Mathematics for Machine Learning — Python Implementations

This repository contains Python code, examples, and notes created while following the course [**Essential Mathematics for Machine Learning**](https://youtube.com/playlist?list=PLLy_2iUCG87D1CXFxE-SxCFZUiJzQ3IvE&si=WNsKGv-2sRKQTOya).  
The goal of this repo is to **connect mathematical theory with practical Python implementations**, especially using NumPy and related scientific tools.

---

## Course Coverage

The repository follows the structure of the course and includes implementations and experiments related to:

### Linear Algebra
- Vectors and matrix algebra
- Vector spaces and subspaces
- Basis, dimension, and linear transformations
- Norms, orthogonality, and projections
- Eigenvalues and eigenvectors
- Special matrices and spectral decomposition
- Singular Value Decomposition (SVD)
- Low-rank approximation
- Principal Component Analysis (PCA)
- Linear Discriminant Analysis (LDA)
- Gram–Schmidt process
- Polar decomposition
- Jordan canonical form

### Calculus
- Limits and derivatives
- Multivariable calculus
- Gradient-based methods
- Python implementations of calculus concepts

### Optimization
- Convex sets and convex functions
- Unconstrained and constrained optimization
- Steepest descent method
- Newton’s method
- Penalty function methods
- Optimization algorithms in Python

### Probability & Statistics
- Probability review
- Bayes’ theorem
- Random variables
- Expectation and variance
- Discrete and continuous distributions
- Joint distributions and covariance

### Machine Learning Foundations
- Least squares and regression
- Logistic regression
- Classification metrics
- Support Vector Machines (SVM)
  - Hard-margin and soft-margin classifiers
  - Duality concepts
  - Python implementations

---

## Purpose of This Repository

- Reinforce mathematical concepts through code
- Translate abstract math into executable Python
- Serve as a personal reference for ML fundamentals
- Build intuition for algorithms used in machine learning and optimization

This is **not** meant to be a polished library, but a learning-focused, evolving codebase.
